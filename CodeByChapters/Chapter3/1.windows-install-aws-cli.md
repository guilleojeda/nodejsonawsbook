In PowerShell, install the current AWS CLI v2 for the current user using AWS's official installer:

```powershell
irm https://awscli.amazonaws.com/v2/install.ps1 | iex
```

Close the current PowerShell window and open a new one so it reads the PATH updated by the installer. Then verify the command is available and check that the version starts with `aws-cli/2`:

```powershell
Get-Command aws
aws --version
```
